Recording order

  1. Event Organizer first — you'll trigger the Session Release scenario here, which is what makes the Government and Attendee reels show a genuinely busy, risk-scored event instead of a quiet one.
  2. Government next, while that scenario is still ramping — the City Risk tiles, map and trend charts read far better with real pressure on screen.
  3. Attendee third — the live crowd banner, notifications and evacuation panel on My Event are only interesting once Suraj Complex IPL is actually under pressure.
  4. Service Provider last, any time — its data (hotel occupancy, forecasts) doesn't depend on the scenario.
Heads up — publishing the Create Event wizard live on camera creates one more real "upcoming" catalog event (e.g. #17). That's by design — non-destructive, doesn't touch the live event — so just let it happen. Delete it afterward from Back Office → Manage Events if you want a tidy catalog; harmless either way if you don't.
